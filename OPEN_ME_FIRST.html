React app is ready

This is a Vite + React + Tailwind CSS application. Do not double-click index.html; Vite must serve the React modules.

Windows — easiest way

Double-click START_APP.bat in this folder. It will install dependencies and start the app.

Or use Terminal

npm install
npm run dev

Then open the localhost URL printed by Vite, normally http://localhost:5173.

The mock files are in public/mock-files/.
